About me

The story so far — education, the journey into code, and the stack I build with.

Developer who ships real software

I am Ahmed Shah, a BSCS undergraduate and full-stack developer working with the MERN stack. I design REST APIs, implement JWT based authentication, build real-time features with Socket.io, and model data in MongoDB with care.

My projects solve concrete problems. A point of sale system for restaurants with a kitchen display and Urdu menus. A learning management platform with role based dashboards. An SEO auditor for Amazon listings that grades and reports. An e-commerce storefront with WhatsApp checkout.

Beyond my own work, I contribute to open source projects maintained by developers I respect — currently hooks for getify's TNG-Hooks library and theming for Wes Bos's Cobalt2 VS Code theme.

I am now looking for a junior developer role, an internship, or freelance projects where I can keep shipping.
